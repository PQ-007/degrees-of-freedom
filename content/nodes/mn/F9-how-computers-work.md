## Роботод яагаад хэрэгтэй вэ

[[F8]]-д бичсэн роботын код хязгаартай жинхэнэ чипүүд дээр ажилладаг: секундэд тодорхой тооны үйлдэл, тодорхой хэмжээний санах ой, мэдрэгчийн уншилтад тодорхой тооны алхам. Доор юу болдгийг мэдвэл тоолуур яагаад гэнэт тэг болдог, уншилт яагаад бага зэрэг зөрдөг, Linux дээрх програм яагаад заримдаа хоцорч хариулдгийг ойлгоно.

## Бит ба тоо

Компьютер бүх зүйлийг [[~bit|бит]]-ээр хадгалдаг, бит бүр 0 эсвэл 1. Нэг бит хоёр утгатай, хоёр бит дөрөв, n бит 2ⁿ утгатай: 8 бит 256 тоо, 16 бит 65 536 тоо өгнө. Хоёртын тооллын систем тоог энэ хоёр цифрээр бичдэг тул 1011 = 8 + 2 + 1 = 11.

Битийн тоо тогтмол учраас тоонууд хязгаартай:

- **Бүхэл тоо эргэн тойрдог.** C++-д тэмдэггүй (unsigned) тооны арифметикийг 2ⁿ-ээр модуль авч гүйцэтгэдэг: хамгийн их утган дээр нэгийг нэмэхэд 0 гарна. Тэмдэгтэй тоо халивал C++ юу болохыг огт тодорхойлдоггүй.[@cpp-overflow] Удаан ажилласан encoder-ийн тоолуурт ийм зүйл тохиолдоно.
- **Бутархай тоо ойролцоо, яг биш.** Ихэнх аравтын бутархай хоёртын яг хэлбэргүй: 0.1-ийг маш ойр тоогоор хадгалдаг тул 0.1 + 0.1 + 0.1 == 0.3 худал гарна.[@python-float] Ийм тоог хэзээ ч == ээр бүү харьцуул.

## Процессор

Процессор буюу CPU санах ойгоос заавруудыг ар араас нь гүйцэтгэдэг. Заавар бүр ижил алхмуудыг дамждаг: татаж авах, юу хүсч байгааг тайлах, гүйцэтгэх; Cortex-M3 зэрэг жижиг микроконтроллерын цөм яг энэ гурван шатыг хийдэг.[@cortex-m3-pipeline] Цаг (clock) хурдыг тогтооно. Arduino UNO-гийн чип 16 МГц хүртэл давтамжтай;[@arduino-uno-r3] Raspberry Pi 5-ийн цаг 2.4 ГГц, 150 дахин хурдан.[@raspberry-pi-5]

## Санах ой

Санах ой хоёр төрөл. RAM хурдан бөгөөд програмын хувьсагч зэрэг ажлын утгуудыг хадгалдаг ч тэжээл тасрахад бүгдийг мартана. Flash тэжээлгүй ч агуулгаа хадгалдаг тул [[~firmware|firmware]]-ийг тэнд хадгалж, асаахад тэндээс ажиллуулдаг.[@arduino-memory]

Хэмжээ нь их ялгаатай. Arduino UNO 32 кБ flash, 2 кБ RAM-тай;[@arduino-uno-r3] Raspberry Pi 5 нь 1-ээс 16 ГБ RAM-тай, хэдэн зуун мянгаас хэдэн сая дахин их.[@raspberry-pi-5] Жижиг чип дээр массив, мөр бүр чухал.

## Оролт ба гаралт

Процессор хөлүүдээрээ гадаад ертөнцтэй харьцдаг. Тоон хөл 0 эсвэл 1-ийг уншиж, бичдэг. Хүчдэл гаргадаг мэдрэгчид [[~adc|ADC]] буюу аналог-тоон хувиргагч хэрэгтэй; тэр хүчдэлийг тоо болгоно. Arduino-ийн ADC 10 битийн: 0–5 В-ыг 0-ээс 1023 хүртэлх тоо болгож, нэг уншилт 100 микросекунд орчим үргэлжилнэ.[@arduino-analogread] Том мессежүүд бусад чип рүү bus-аар дамждаг ([[C12]]).

## Тасалдал

Програм хөлийг дахин дахин шалгаж болох ч өөр ажилтай байх зуураа богино импульсийг алгасаж магадгүй. [[~interrupt|Тасалдал]] нь тоног төхөөрөмжид процессорыг зогсоож, зохицуулагч (handler) гэдэг богино функцийг ажиллуулаад, зогссон газар нь буцаах боломж олгодог. Arduino rotary encoder уншихад тасалдал ашиглахыг зөвлөдөг; зохицуулагч аль болох богино, хурдан байх ёстой, дотор нь `delay()` ажиллахгүй, түүний өөрчилдөг хувьсагчдыг `volatile` гэж тэмдэглэх хэрэгтэй.[@arduino-interrupts]

```cpp
volatile long count = 0;   // зохицуулагч дотор өөрчлөгдөнө

void onPulse() {           // зохицуулагч: богино, хурдан
  count++;
}

void setup() {
  attachInterrupt(digitalPinToInterrupt(2), onPulse, RISING);
}
```

2-р хөл дээрх encoder-ийн импульс бүр `loop()` тэр мөчид юу хийж байгаагаас үл хамааран `count`-д нэгийг нэмнэ.

## Үйлдлийн систем

[[~operating-system|Үйлдлийн систем]] нэг процессор дээр олон програм ажиллуулдаг. Аль ч мөчид зөвхөн нэг ажил ажилладаг; scheduler дараа нь алийг ажиллуулахыг шийдэж, сэлгэх бүрд ажил бүрийн байрыг хадгална.[@freertos-scheduler]

Энгийн Linux дээр яаралтай ажил ажиллаж эхлэхээсээ өмнө хэсэг хүлээж болно; PREEMPT_RT хувилбар энэ хүлээлтийг богиносгодог.[@linux-preempt-rt] Микроконтроллер дээр бодит хугацааны үйлдлийн систем ажлуудад хатуу эрэмбэ өгч, бэлэн байгаа хамгийн яаралтайг нь үргэлж ажиллуулдаг тул хугацааг нь урьдчилан тооцож болно.[@freertos-scheduler] [[~real-time|Бодит хугацааны]] гэдэг нь ийм: хоцорсон хариу буруу хариутай адил.

<details class="deeper">
<summary>Гүнзгийрүүлэх: тэгшитгэлүүд</summary>

n бит хэдэн тоо хадгалах вэ:

$$
L = 2^{n}
$$

$V_\text{ref}$ жишиг хүчдэлтэй ADC түүнийг дараах алхмуудад хуваана:[@arduino-analogread]

$$
\Delta = \frac{V_\text{ref}}{2^{n}}
$$

тэгээд $v$ хүчдэл аль алхамд байгааг мэдээлнэ:

$$
k = \left\lfloor \frac{v}{\Delta} \right\rfloor
$$

тиймээс уншилт жинхэнэ утгаас нэг хүртэлх алхмаар доогуур байна:

$$
0 \le v - k\,\Delta < \Delta
$$

Тэмдэггүй n битийн арифметик эргэн тойрдог:[@cpp-overflow]

$$
(a + b) \bmod 2^{n}
$$

</details>

## Түгээмэл алдаа

- Бутархай тоог == ээр харьцуулах, гэтэл тэд сүүлийн цифрээрээ ялгаатай байж болно.[@python-float]
- Тоолуурыг халиулах: хамгийн урт ажиллагаанд хүрэлцэх биттэй төрлийг сонго.
- Тасалдлын зохицуулагч дотор удаан ажил хийх, эсвэл түүний хуваалцдаг хувьсагчид `volatile` тавихаа мартах.[@arduino-interrupts]
- Энгийн Linux дээрх програмаас яг нарийн хугацаа хүлээх.

## Хаашаа хөтөлдөг вэ

[[C11]] роботын ашиглаж болох чип, компьютеруудыг харьцуулж, [[C12]] тэдгээрийн хоорондох bus ба холбоосыг авч үзнэ.
