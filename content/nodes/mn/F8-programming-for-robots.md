## Роботод яагаад хэрэгтэй вэ

Утас холболтоос цааш роботын хийдэг бүхэн код юм: мэдрэгч унших, шийдэх, хөдөлгүүр удирдах. Робот ихэвчлэн кодоо хэд хэдэн газар ажиллуулдаг бөгөөд газар бүрд тохирох хэл байдаг. Эхний өдрөөс бүгдийг нь мэдэх шаардлагагүй ч аль нь хаана ажилладгийг мэдэх хэрэгтэй.

## Хэл бүр хаана ажилладаг вэ

Python ба MATLAB гэж тэмдэглэсэн зөөврийн компьютер тасархай шугамаар, буюу сүлжээгээр, процессор, нэг эгнээ хөл, хоёр порттой хэлхээний хавтантай холбогдсон; хавтанд Linux, C++ ба Python, ROS 2 гэж бичсэн. Хавтанг хөлтэй жижиг чиптэй бүтэн утас холбосон, чипэнд C ба C++ гэж бичсэн, нимгэн утас чипийг хөдөлгүүртэй холбоно.](fig:languages-map "Хэл бүр хаана ажилладаг вэ: таны компьютер дээр Python ба MATLAB, роботын компьютер дээр Linux, C++ ба Python, хөдөлгүүрийг удирддаг микроконтроллер дээр C эсвэл C++.")

- **Микроконтроллер дээр:** C эсвэл C++ хэлээр бичсэн [[~firmware|firmware]]; тэжээл орж ирэхэд эхэлж, хөлүүдийг шууд ажиллуулна.
- **Роботын компьютер дээр:** Linux, [[S2]]-оор хоорондоо ярьдаг C++ ба Python програмууд. Хоёр хэлээр бичсэн node-ууд мессеж солилцож чадна.[@ros2-client-libraries]
- **Таны компьютер дээр:** загвар сургаж, өгөгдөл харахад Python, роботыг бүтээхээс өмнө загварчилж, симуляц хийдэг хэрэгслүүд.

## C ба C++: тоног төхөөрөмжид ойр

[[~compiler|Компилятор]] C ба C++ кодыг ажиллуулахаас өмнө процессорын өөрийн зааварт хөрвүүлдэг тул [[~microcontroller|микроконтроллер]] түүнийг шууд гүйцэтгэнэ. Arduino-ийн sketch-ийг C++ програм болгож, gcc ба g++-ээр компиляц хийдэг.[@arduino-sketch-cpp]

Sketch хоёр хэсэгтэй: `setup()` тэжээл орох эсвэл reset хийх бүрийн дараа нэг удаа ажиллаж, дараа нь `loop()` дахин дахин ажиллана.[@arduino-setup-loop] Энд урд талын мөргөлтийн товч дарагдахад робот зогсоно: мэдрэх, бодох, үйлдэх, секундэд олон удаа.

```cpp
const int BUMPER = 2;  // урд талын товч
const int MOTOR = 9;   // хөдөлгүүрийн драйвер руу PWM хөл

void setup() {         // нэг удаа, асаахад
  pinMode(BUMPER, INPUT_PULLUP);
  pinMode(MOTOR, OUTPUT);
}

void loop() {          // дахин дахин
  bool hit = digitalRead(BUMPER) == LOW;  // мэдрэх
  int duty = hit ? 0 : 127;               // бодох
  analogWrite(MOTOR, duty);               // үйлдэх
}
```

`INPUT_PULLUP` товч хөлийг газардуулгатай холботол түүнийг өндөр түвшинд барина, тиймээс дарахад `LOW` уншигдана. `analogWrite` бол [[F7]]-ийн [[~pwm|PWM]]: 255-аас 127 нь хугацааны тал орчим нь асаалттай гэсэн үг.[@arduino-pwm]

## Python: хурдан бичигддэг

Python-д тусдаа build алхам хэрэггүй: програмаа өөрчлөөд шууд дахин ажиллуулна. Тиймээс хэрэгсэл бичих, хурдан туршихад тохиромжтой, харин үр ашигтай байх ёстой хэсгийг ихэвчлэн C++-ээр бичдэг.[@ros2-client-libraries] Өргөн хэрэглэгддэг машин сургалтын хэрэгслүүд ч бас Python-д зориулагдсан.[@pytorch]

Энэ ROS 2 node зай хэмжигчийг сонсож, ямар нэг юм ойрхон байвал анхааруулна. Node бол нэг жижиг програм; ROS 2 node-уудын хооронд мессеж дамжуулдаг.

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Range

class Watch(Node):
    def __init__(self):
        super().__init__("watch")
        self.create_subscription(
            Range, "front_range", self.on_range, 10)

    def on_range(self, msg):
        if msg.range < 0.2:  # метр
            self.get_logger().info("Obstacle ahead")

rclpy.init()
rclpy.spin(Watch())
```

`create_subscription` нь `front_range` topic-ийн мессеж бүрийг хүлээн авахыг хүсэж, `spin` програмыг тэднийг хүлээлгэн байлгаж, мессеж бүрд `on_range`-ийг дуудна.

## Linux ба терминал

Роботын компьютер олонтаа Linux дээр ажилладаг: Linux-ийн нэг болох Ubuntu бол ROS 2-ийн хамгийн сайн дэмждэг платформуудын нэг.[@ros2-jazzy-platforms] Ихэнхдээ дэлгэцгүй байдаг тул та өөрийн компьютероосоо терминалд тушаал бичиж ажиллана. Тушаалууд богино бөгөөд тус бүр нэг ажил хийнэ:

```sh
ssh me@rover.local    # сүлжээгээр робот руу нэвтрэх
cd rover              # төслийн хавтас руу орох
ls                    # доторх зүйлсийг жагсаах
python3 watch.py      # програмыг ажиллуулах
```

Бичсэн тушаалуудыг файлд хадгалаад яг адилхан дахин ажиллуулж болно; товшилтоор үүнийг хийхэд хэцүү.

## Git: хувилбар бүр хадгалагдана

[[~version-control|Хувилбарын хяналт]] төслийн хадгалсан хувилбар бүрийг хэн юуг яагаад өөрчилснийх нь хамт хадгалдаг. Git бол үнэгүй, нээлттэй эхийн хувилбарын хяналтын систем.[@git-vcs] Нэг өөрчлөлтийн дараа робот явахаа больвол яг юу өөрчлөгдснийг хараад буцаж болно.

```sh
git add watch.py
git commit -m "Warn when an obstacle is close"
git log --oneline     # хадгалсан хувилбарууд, шинэ нь эхэндээ
```

Commit бол хадгалсан нэг хувилбар. Жижиг алхам бүрийг яагаад хийснийг бичсэн мессежтэй commit хий, тэгвэл ажилладаг робот хэзээд нэг алхмын цаана байна.

## Таарах бусад хэлүүд

- **Rust** C++ шиг компиляц хийгддэг ч програм ажиллахаас өмнө санах ойн хэрэглээг шалгадаг тул олон төрлийн алдааг арилгадаг; garbage collector байхгүй тул жижиг төхөөрөмж дээр ажиллаж чадна.[@rust-safety]
- **Блок диаграм.** Зарим хэрэгсэл системийг холбосон блокуудаар зурж, симуляц хийж, зурагнаас нь тоног төхөөрөмжийн кодыг үүсгэх боломж олгодог.[@simulink]

## Түгээмэл алдаа

- `loop()` дотор хүлээх, жишээ нь урт `delay()`: хүлээж байх хооронд робот мэдрэгчээ уншихаа болино.
- Роботын компьютер дээрх хурдан дотоод давталтыг Python-оор бичих, уг нь firmware эсвэл C++-д байх ёстой.
- Буцах commit-гүйгээр ажиллаж байгаа кодыг өөрчлөх.
- Нэгжийг хэлэлгүй холих: дээрх код шиг метр, секунд, радианыг тооны хажууд бич.
