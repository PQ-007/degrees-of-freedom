T3 · M5

Classical control

NeedsF2 CalculusL4 Motor control Used byM9 Whole-body controlI6 Legged locomotion

Don't just command: measure and correct. A feedback loop compares where the joint is with where it should be, and pushes in proportion to the error. That one idea turns a sloppy motor into a precise one, as long as the loop doesn't overshoot and oscillate.

Every robot in this atlas runs loops like this, nested inside each other: a current loop inside a velocity loop inside a position loop, each one faster than the one around it.

Common mistakeIntegrating with a fixed dt when the loop actually runs late. Measure dt every cycle.
Go deeper: the PID law

u(t) = Kp·e(t) + Ki·∫e dt + Kd·de/dt

u = kp * err + ki * integral + kd * (err - prev) / dt
u = clamp(u, -u_max, u_max)   # saturate, then anti-windup

Unstable: the gain is too high, so the demo stopped the simulation.
